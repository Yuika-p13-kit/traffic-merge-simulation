# Highway merge v3 — Step 6 事前評価計画: 固定間隔Ramp Metering

## 背景と目的

Step 5では、高需要・ランプ偏重（3,950 veh/h、主線:ランプ=1:2）の完全版TTSの80.2%が道路外のランプ挿入待ちだった。主線への速度助言を追加してもbreakdownは回復しなかった。Step 6では主線を減速・停止させず、ランプの投入タイミングだけを制御する固定間隔Ramp Meteringを検証する。

## 比較条件

- ネットワーク: `highway_merge_v3`
- 総需要: 3,950 veh/h（主線1,317、ランプ2,633 veh/h）
- 投入・クリアランス: 1,800秒・600秒
- seed: 7 / 42 / 99 / 123 / 2026
- 戦略: 無制御、固定1.0秒、固定1.25秒、固定1.5秒

旧`minimal_merge`の4/6/8秒間隔は使わない。各放流上限は900/600/450 veh/hであり、v3のランプ需要2,633 veh/hを構造的に下回るためである。1.0/1.25/1.5秒はそれぞれ3,600/2,880/2,400 veh/hに相当し、需要より上・近傍・下の制約強度を比較できる。

## 実装仮説

ランプ上流の1地点で先頭車両を一時保持し、次の放流時刻に到達済みの先頭1台だけを解除する。主線は制御しない。固定間隔によって、並走区間へ短時間に集中するランプ到着を平準化できれば、合流部の不安定化を弱められる可能性がある。

## 判定

主指標は完全版TTS（道路内滞在＋道路外挿入待ち）である。無制御との同一seed差について95% Student-t信頼区間を計算し、上限が0未満なら改善、下限が0超なら悪化とする。副指標は主線・ランプ別TTS、未完了台数、処理量、衝突、テレポート、放流回数である。

固定方式が改善しなくても、有効性を同一条件で検証し適用限界を定量化できれば、Step 6初期目標は達成と判定する。固定方式が未達の場合は、オンデマンド方式またはALINEAへ進む。
