# Highway merge v3 — Step 6-2 結果: 0.25秒刻みの固定間隔Metering

## 結論

固定間隔Ramp Meteringは終了する。0.25秒刻みにより非整数間隔を表現できるようにして再評価したが、完全版TTSの95%信頼区間が改善側だけに入る固定方式はなかった。Step 6-2の判定基準「改善がなければ固定方式を終了する」を満たした。

## 条件

- `highway_merge_v3`、3,950 veh/h（主線1,317、ランプ2,633）、主線:ランプ=1:2
- 需要投入1,800秒、クリアランス600秒、seed 7 / 42 / 99 / 123 / 2026
- `step-length=0.25`秒。全戦略で完全版TTSを同じ0.25秒刻みで積分
- 無制御、限定協調合流、固定1.0 / 1.25 / 1.5秒
- 衝突・テレポートはいずれも0

## 追加の観察

0.25秒刻みでは無制御の処理量は3,952 veh/h、未完了台数は0台となった。これはStep 6の1秒刻みで見えたbreakdownが数値時間刻みの影響を強く受けていたことを示す。したがって、Step 6の固定Metering比較を1秒刻みの結果だけで結論づけず、今回再評価したことには意味がある。
